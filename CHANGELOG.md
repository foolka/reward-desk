# Изменения

## 0.3.0 — 2026-10-17

- Рулетки звука и видео по умолчанию выбирают без повторов, пока не закончатся все файлы с положительным весом. Цикл отдельный для каждой награды, общий для всех зрителей и сохраняется между перезапусками.
- Опция «Полный рандом с повторениями» возвращает прежний независимый взвешенный выбор. В циклическом режиме вес влияет на порядок, а не число показов за цикл.
- На границе циклов исключён немедленный повтор последнего файла, если доступно больше одного. Повтор события Twitch, повтор прерванного задания и тест отдельного файла не расходуют новый выбор; выбор и запись очереди сохраняются атомарно.
- Компактный список медиа: заголовки колонок один раз, громкость и процент в одну строку, уменьшены интервалы и размеры кнопок. Исправлено повторное изменение веса и громкости после сохранения.
- Предпросмотр и OBS используют одну геометрию кадра. Рамка учитывается при вписывании широких, вертикальных и квадратных роликов; добавленных полос нет. Кадр не обрезается и не растягивается.
- Маленькие «?» возле настроек: подсказки при наведении, фокусе с клавиатуры и нажатии. Доступны также для наград только для просмотра; текст не выходит за край окна.
- Сохранены настройки, медиа, очередь, история и ссылка OBS. Уже выбранные файлы в существующих заданиях не заменяются.

## 0.2.1 — 2026-10-17

- Единый шеврон с отступом 12 px во всех выпадающих списках, включая настройки видео.
- Фильтры в колонках наград канала: несколько цветов, название и состояние, диапазон баллов с включёнными границами.
- Сортировка по цвету, названию и числу баллов: по возрастанию, убыванию и возврат к исходному порядку.
- Совместное применение фильтров, счётчик результатов и сброс. Фильтрация не меняет награды Twitch и не теряет несохранённые настройки редактора.
- Проверены узкие окна и размещение всплывающих фильтров в пределах экрана.

## 0.2.0 — 2026-10-17

- Вкладка «Награды канала»: все пользовательские награды Twitch, цвета, цены, статусы, поиск и фильтр по возможности редактирования.
- Редактор доступных через текущий Client ID наград: название, описание, стоимость, цвет, доступность, пауза, сообщение зрителя, лимиты и перезарядка.
- Для наград из других приложений доступен просмотр настроек и переход в панель Twitch. Ограничение на изменение задаётся Twitch API.
- Единая форма настроек для новых медиа-наград и существующих наград канала.
- Проверка изменения аккаунта и устаревших настроек перед сохранением. Обновление списка восстанавливает настройки после потерянного ответа Twitch без повторной отправки.
- Сохраняются медиа, громкости, веса, оформление видео, история и постоянная ссылка OBS.
- Подтверждение ухода из несохранённого редактора; исправлена привязка полей после фонового обновления состояния.
- Новые автоматические проверки и скриншот вкладки.

## 0.1.1 — 2026-10-16

- Исправлено восстановление создания награды через кнопку после потерянного ответа Twitch.
- Индикатор рулетки обновляется сразу при добавлении/удалении файла.
- Пауза перед удалением отражается и в локальных настройках награды.

## 0.1.0 — 2026-10-16

Первый приватный выпуск Reward Desk.

- Отдельная Windows-программа и установщик, собственный профиль и Git.
- Прямой OAuth Device Code Flow и EventSub Twitch, без Streamer.bot.
- Управление наградами канала и доступными настройками Twitch.
- Звуковые и видео-рулетки, веса и громкость каждого файла.
- Визуальное размещение видео, рамка, скругление и случайный наклон.
- Постоянный OBS-источник, очередь, тесты, история, подтверждение и возврат баллов.
- Защита от повторов, восстановление соединения и прерванного проигрывания.
- Скриншоты, инструкции и автоматические проверки.
